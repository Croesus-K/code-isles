# 产品方案：像素 RPG 风格学习平台「代码群岛 Code Isles」

> 状态：产品方案已确认（2026-09-15）；商业化路线已确认（免费网页 + 打赏赞助）；仓库可见性待定。

## 一、定位

用像素 RPG 的外皮和机制学**正经知识**——不是"教你做游戏"的工具。玩家扮演冒险者，在世界地图上闯关，关卡内容就是 Python 知识点。浏览器打开即用，无需安装。

## 二、学习闭环设计（核心循环）

```
世界地图 → 选区域 → 关卡任务 → 学习卡 → 答题挑战 → XP/金币/星级
    ↑                                                    │
    └────── Boss关通过 → 区域徽章 → 解锁下一区域 ←────────┘
```

| 环节 | 设计 |
|---|---|
| 关卡任务 | 一个知识点 = 一关。先看"学习卡"（一张卡片讲一个概念 + 短示例），然后连续答 4~6 题 |
| 答题判定 | 答对得 XP 和金币，连对触发连击加成；答错不扣血，当场给解析，可花金币买提示 |
| 星级评价 | 按错误次数和提示使用数给 1~3 星，三星需要全对无提示——鼓励回头刷关复习 |
| 解锁推进 | 过一关解锁下一关；区域末尾有 Boss 关（本区域综合测验），打赢才解锁下一区域、掉落区域徽章 |
| 角色成长 | XP 累积提升冒险者等级；金币攒着换提示，后期可换角色装扮 |
| 收集要素 | 徽章墙：区域徽章、全三星徽章、连胜徽章等，收集感驱动完课率 |

v1 不做：账号系统、云存档、每日任务。存档存浏览器本地（localStorage），支持导出/导入 JSON 文件备份。

## 三、首期课程：Python 基础

参考 pixel-forge roadmap 的知识阶梯，映射为 5 个区域：

| 区域 | 知识点 | Boss 关 |
|---|---|---|
| 1 变量平原 | 变量、数字与运算符、字符串入门 | 综合测验 |
| 2 分支森林 | 布尔与比较、If/Else、逻辑运算 | 综合测验 |
| 3 循环洞窟 | For 循环、While 循环、break/continue | 综合测验 |
| 4 列表湖 | 列表基础、增删改查、切片 | 综合测验 |
| 5 字典城 | 字典、函数入门、综合应用 | 毕业大测验 |

题型 5 种：选择题（概念）、输出预测（给代码猜结果）、代码填空（补全空位）、代码排序（打乱的行拖回正确顺序）、找错题（指出哪行有 bug）。

v1 不真运行 Python 代码（答案预置判定）；后续里程碑可加 Pyodide（浏览器里跑真 Python），做"写代码运行验证"类关卡。

架构上课程内容做成独立数据包（JSON/TS 数据文件），代码与内容分离——以后加"Git 基础""SQL 入门"等新课程不用改引擎代码。

## 四、页面结构（6 个页面）

1. 标题页 — 开始冒险 / 继续冒险（读档）
2. 世界地图 — 区域节点俯瞰，锁定区域置灰上锁
3. 区域地图 — 关卡节点连成路径，显示星级，Boss 节点更大
4. 关卡页 — 学习卡 → 逐题作答 → 结算（XP/金币/星级/掉落）
5. 角色页 — 等级、XP 条、金币、徽章墙
6. 设置页 — 音效开关、存档导出/导入、重置进度

以桌面浏览器为主，基础响应式适配平板。

## 五、技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 形态 | 纯静态网页（Vite 构建） | 打开即用，托管免费 |
| 框架 | React 18 + TypeScript | 组件化适合关卡/题型复用，生态成熟好维护 |
| 状态 | Zustand + localStorage 存档（带版本号，支持迁移） | 轻量 |
| UI | 手写 CSS 像素设计系统（image-rendering: pixelated、步进动画），不引 UI 库 | 商用组件库会毁掉像素感 |
| 不用游戏引擎 | 地图/角色用 DOM+CSS+少量 Canvas | 没有物理需求 |
| 测试 | Vitest（判定逻辑、存档、课程数据 schema 校验） | 保证判题不出错 |
| 托管 | 公开仓库 → GitHub Pages；私有仓库 → Vercel/Netlify 免费档 | 待定 |

## 六、素材与授权（规避 craftpix 风险）

- 图标/UI 素材：优先 Kenney.nl（全部 CC0，可商用、免署名、无再分发风险），够不着的部分脚本自制像素图
- 中文字体：缝合像素字体 Fusion Pixel Font（OFL 开源协议，支持中文、可商用）；不用 Zpix（商用需付费授权）
- 音效：Kenney CC0 音效包，或用 jsfxr 自生成复古音效
- README 附素材来源清单与授权说明（商业化的合规凭证）

## 七、开发里程碑

| 里程碑 | 内容 | 产出 |
|---|---|---|
| M0 | 脚手架 + 像素设计系统 + 存档系统 | 本地打开，像素风骨架页 |
| M1 | 世界地图 + 区域地图 + 关卡流程跑通 | 能从地图点进关卡答完第一套题 |
| M2 | 5 种题型 + XP/金币/星级/解锁逻辑 | 完整闭环可玩（区域1） |
| M3 | 5 个区域课程内容全部填充 | 全课程通关流程 |
| M4 | 徽章系统 + 音效 + 动画打磨 | 收集要素齐全 |
| M5 | 部署上线（Pages/Vercel） | 拿到网址，浏览器直接玩 |
| M6+（可选） | Pyodide 真代码运行、每日任务、第二门课 | 后续迭代 |

每个里程碑收尾固定流程：变更清单过目 → 批准 → grep 扫描（本地路径、真实邮箱）→ commit + push。

## 八、项目名

已定：**code-isles（代码群岛）**——世界地图是一片群岛，每门课是一座岛（Python 岛、将来的 Git 岛……），扩展性最贴定位。

## 九、商业化路线（2026-09-15 已确认）

采用：**免费网页版攒用户 + 打赏赞助**。

- 产品本体永久免费：不做内购、不做广告、不做订阅
- 攒用户优先于变现：第一目标是传播品质与留存数据，而非收入
- 上线（M5）后挂打赏渠道：GitHub Sponsors（平台零抽成）、爱发电等
- 远期备选（仅在数据验证后再议，当前不做）：Steam 买断、微信小游戏纯广告版
- 商业化调研结论备查：内购类小游戏需版号（个人不可行）；小游戏/小程序发布需备案；Steam 上架费 $100/款——这些都写在远期备选的门槛里
